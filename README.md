# Productivity Dashboard

A full-stack web application that helps users organize tasks, track productivity, and gain insights into how they spend their time. The goal of this project is to create a centralized dashboard that combines task management, scheduling, and personal analytics in a clean, user-friendly interface.

## Features (Planned)

- User authentication
- Task creation and management
- Dashboard with daily and weekly tasks
- Productivity statistics
- Interactive charts and visualizations
- Calendar integration
- Goal and habit tracking
- Personalized productivity insights

## Tech Stack

**Frontend**
- React
- HTML/CSS
- JavaScript

**Backend**
- Python
- Flask

**Database**
- SQLite (development)
- PostgreSQL (future)
