# Olivia's Super Awesome (ish) Planner

A full-stack planner application built with React, Flask, and SQLite that helps users organize tasks and schedules in one place.

# Features
Add tasks with due dates
Mark tasks as complete
Delete completed tasks
Add scheduled events with dates and times
View tasks and events grouped by date
Delete individual schedule events

JavaScript
Flask
